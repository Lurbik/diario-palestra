# Checklist prove reali su Android (da fare tu)

Nessuna di queste prove è stata eseguita su un telefono reale. Segna ✅/❌ e annota modello e versione Android.

Modello / versione Android: __________________   Chrome versione: __________

## Installazione
- [ ] Apertura su `http://localhost:4173` (port forwarding) o indirizzo HTTPS.
- [ ] In Oggi compare "● Pronta offline".
- [ ] Menu ⋮ → "Installa app" disponibile; icona in schermata Home; si apre a schermo intero.

## Offline
- [ ] Modalità aereo → apri l'app dall'icona → si avvia.
- [ ] Chiudi completamente l'app (scorri via dalle recenti), riaprila in modalità aereo → si avvia.

## Seduta
- [ ] Avvia una seduta, registra una serie con carico/ripetizioni/RIR → conferma "Serie salvata ✓".
- [ ] Doppio tocco veloce su "Salva serie" → una sola serie nello storico.
- [ ] RIR "Non so" → nello storico appare "RIR non so" (non 0).
- [ ] Dettagli serie: 6 complete + 3 parziali extra → mostrato "× 6 … +3 parziali extra".
- [ ] Inserisci ripetizioni senza salvare, blocca lo schermo 2 minuti, sblocca → valori ancora presenti.
- [ ] Inserisci ripetizioni senza salvare, chiudi l'app dalle recenti, riapri → seduta e bozza ripristinate.
- [ ] Timer di recupero: blocca lo schermo durante il recupero, sblocca dopo 1 minuto → il tempo è corretto.
- [ ] Modifica una serie salvata e annulla una serie dal messaggio "Annulla".
- [ ] (Facoltativo) vibrazione/suono a fine recupero con app aperta; schermo acceso se attivato.
- [ ] Uso con una mano: pulsanti raggiungibili, tastiera numerica con virgola nei campi numerici.

## Backup
- [ ] Altro → Backup → "Scarica backup completo": il file appare in Download.
- [ ] Backup cifrato con password; importazione con password errata → messaggio "Password errata".
- [ ] Importazione dello stesso backup in modalità "Unisci" → anteprima con 0 nuovi; nessun duplicato.
- [ ] Esportazione CSV apribile (es. Fogli Google / Excel).

## Aggiornamento
- [ ] Con una nuova build disponibile e una seduta attiva: avviso "aggiorna dopo la seduta", pulsante disabilitato.
- [ ] Dopo aver terminato la seduta: "Aggiorna" → l'app si ricarica, storico e serie presenti.

## Altro
- [ ] Tema scuro/chiaro e alto contrasto leggibili in palestra.
- [ ] Zoom del testo di Android al 130%: nessun contenuto tagliato.
- [ ] Altro → Backup: stato "Archiviazione persistente" (annota se concessa).
